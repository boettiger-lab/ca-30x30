# Disclosure: use of software tools

Portions of the configuration, documentation and validation analyses in this repository, in particular the app configuration (`layers-input.json`, `index.html`, `k8s/`), the agent system prompt (`system-prompt.md`) and the reproduction of the 2025 Biodiversity Assessment statistics, were drafted with the aid of large language model coding tools: Anthropic Claude models, including Claude Opus 5.5 (model ID `claude-opus-5-5`), accessed through the Claude Code command-line tool, beginning August 2026.

The authors directed this work and reviewed, tested, and validated the results, including benchmark runs of the deployed agent and comparison of reproduced figures against the published assessment. The authors take full responsibility for the code, analyses, and text, and any errors they contain.
